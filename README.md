# TwFarmer

Консольная программа на Rust: вход в свой аккаунт Twitch, просмотр выбранных
онлайн-каналов и получение доступных бонусных баллов.

## Быстрый запуск

Нужен установленный Rust с Cargo. В каталоге проекта:

```bash
cargo build --release
./target/release/twfarmer init channel1 channel2
./target/release/twfarmer login
./target/release/twfarmer run
```

Вместо `channel1 channel2` укажите логины стримеров. Можно передавать ссылки
`https://www.twitch.tv/channel`, разделять имена запятыми; дубликаты удаляются.
При входе программа покажет ссылку и код: откройте ссылку, войдите в свой аккаунт
на Twitch и подтвердите подключение. Пароль и 2FA вводятся на сайте Twitch.
Повторные запуски используют сохранённую сессию.

Можно просто выполнить `cargo run --release`: при первом запуске программа
запросит каналы и начнёт вход. `Ctrl+C` останавливает программу.

## Команды

```bash
cargo run --release -- init channel1 channel2 channel3
cargo run --release -- login
cargo run --release -- run
cargo run --release -- run channel3 channel4
cargo run --release -- status
cargo run --release -- logout
cargo run --release -- --config another.toml run
```

`init` создаёт `twfarmer.toml` и не перезаписывает существующий файл.
`run` с аргументами заменяет каналы только на текущий запуск.
`status` показывает онлайн-статус и баланс, без запуска просмотра и получения бонусов.
`logout` удаляет локальный файл сессии; для отзыва доступа используйте настройки
подключений Twitch: https://www.twitch.tv/settings/connections.

## Настройки

Пример — `twfarmer.example.toml`. Основные поля:

- `channels`: список логинов в порядке приоритета.
- `max_channels`: 1 или 2. Используются первые подходящие онлайн-каналы.
  Когда эфир заканчивается, программа переключается на следующий канал.
  Каналы с отключёнными или недоступными баллами пропускаются.
- `poll_interval_seconds`: проверка каналов и балансов, 30–3600 с; по умолчанию 60.
- `watch_interval_seconds`: обращение к потоку и событие просмотра, 15–60 с;
  по умолчанию 20.
- `claim_bonus`: автоматически получать доступные бонусы; по умолчанию true.
- `client_id`, `oauth_scopes`: параметры OAuth. По умолчанию используются
  публичный ID TV-клиента Twitch и минимальный legacy scope `user_read`.
  Регистрация собственного приложения не нужна. Это неофициальный клиент;
  при изменениях Twitch параметры и запросы могут потребовать обновления.
  Смена `client_id` требует повторного `login`; произвольный ID не гарантирует
  доступ к внутреннему GraphQL API.

Программа загружает один сегмент потока низкого качества на каждом такте
просмотра и отправляет событие `minute-watched`. ID зрителя передаётся числом.
Адрес событий выбирается из текущих настроек Twitch: при
`use_beacon_url = true` используется `beacon_url`, иначе — `spade_url`.
Видео не воспроизводится на экране и не записывается на диск. Требуются сеть
и некоторое количество трафика. Решение о начислении принимает Twitch.

На канале с нулевым балансом первое начисление приходит не сразу. Для обычных
баллов за просмотр типичный интервал — около 5 минут, а отображение может
задерживаться. Нулевой баланс после нескольких коротких проверок ещё не
означает, что первый просмотр не засчитывается. Окончание эфира прекращает
начисление независимо от текущего баланса.

Баланс и его изменение выводятся из ответа Twitch. Успешная отправка события
просмотра сама по себе не подтверждает начисление. Проверьте изменение баланса
через 10–15 минут работы; если баланс не растёт, текущий механизм может быть
непригоден для вашего аккаунта или Twitch мог его изменить.

## Сессия и ограничения

Токены сохраняются рядом с конфигурацией: `twfarmer.toml.auth.json`.
На Unix файл создаётся с правами 0600 и заменяется атомарно.
На Windows доступ определяется правами каталога. Файл содержит токены в открытом
виде: не передавайте его другим людям. Файл исключён из Git; токены не выводятся
в журнал и не отправляются вместе с запросами к CDN. Для независимых аккаунтов
используйте разные пути `--config`.

Сессия проверяется при запуске и каждые 5 минут. TV-токен с `expires_in = 0`
считается действительным, если Twitch подтверждает его через `/validate`.
Refresh token используется после отказа `401` или при положительном остатке
срока не более 5 минут, если Twitch его предоставил. Когда обновить сессию невозможно, выполните
`login` снова. При сетевых ошибках просмотр повторяется с увеличением задержки
до 5 минут. Устаревшие GraphQL-запросы отображаются как ошибки.

Официальный Twitch API не предоставляет фарм баллов зрителя. Здесь используются
внутренние GraphQL-запросы, OAuth TV-клиента и события просмотра. Их доступность
и начисление баллов не гарантированы; автоматический фарм может противоречить
правилам Twitch и привести к ограничениям аккаунта. Ставки и расходование баллов
не предусмотрены.

## Проверка

```bash
cargo fmt --check
cargo test
cargo clippy --all-targets -- -D warnings
```

Тесты проверяют обработку каналов, OAuth-ответов, сохранение сессии, выбор
HLS-качества и сегментов, разбор баланса и ошибок GraphQL. Проверка реального
начисления требует входа в аккаунт и работающего эфира.
