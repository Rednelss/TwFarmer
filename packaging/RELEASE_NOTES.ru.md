TwFarmer 0.3.0 добавляет автообновление из GitHub и заменяет вход по коду устройства входом по нативному токену. Подключённые кампании Drops доступны до первой минуты просмотра.

- Автообновление включено по умолчанию. Проверка при запуске и каждые 24 часа,
  скачивание архива своей платформы, проверка `SHA256SUMS` и перезапуск
  с активными аккаунтами и каналами. В Linux сохраняется PID службы.
- `update --check` проверяет релиз без установки, `update` устанавливает его.
  Обе команды доступны через меню. Отключить автообновление можно через
  `settings set --auto-update false` или настройки фарма.
- `login` принимает нативный токен или адрес перенаправления Twitch со скрытым
  вводом. Логин определяется автоматически. `F2` копирует полную ссылку входа.
  Браузер на компьютере с программой не требуется, в том числе на VDS.
- Привязка Drops проверяется отдельно для каждой кампании и аккаунта.
  Для старта подключённой награды не нужно сначала смотреть канал в браузере;
  неподключённые игры исключаются.
- Списки каналов и настройки совместимы. Прежние настройки ID клиента
  и OAuth scopes игнорируются. Ежедневные награды продолжают использовать
  время сброса из ответа Twitch для каждого аккаунта.

При переходе с 0.2.x один раз установите бинарник 0.3.0 вручную. Старые TV-сессии
без доступа к привязкам кампаний требуют нового `login` для каждого Twitch-аккаунта.
Используйте прежний каталог или `--config`, чтобы сохранить списки каналов.

Сборки: Linux x86_64 (glibc 2.35+), Windows x86_64, macOS Apple Silicon.
Для обновления нужны права записи в каталог программы. Если обновление
установлено отдельной командой `update`, работающий экземпляр нужно перезапустить.
Проверьте скачанный архив по `SHA256SUMS` из релиза.
