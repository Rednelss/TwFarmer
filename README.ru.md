# TwFarmer

[English](README.md) | **Русский**

Консольная программа на Rust для фарма баллов, бонусов и Drops на Twitch
с нескольких аккаунтов. Аккаунты называются по их логинам Twitch; отдельные имена
при добавлении придумывать не нужно.

## Установка и запуск

Готовые архивы доступны на странице
[GitHub Releases](https://github.com/Rednelss/TwFarmer/releases).
Выберите Linux x86_64, Windows x86_64 или macOS Apple Silicon, распакуйте архив
и запустите `twfarmer` (`twfarmer.exe` на Windows) из распакованной папки.
Linux-сборка из GitHub Actions требует glibc 2.35 или новее.
Для проверки скачанного архива сравните его SHA-256 с файлом `SHA256SUMS` релиза;
на Linux: `sha256sum --ignore-missing --check SHA256SUMS`.

Для сборки из исходников нужны Rust 1.89+ и Cargo:

```bash
git clone https://github.com/Rednelss/TwFarmer.git
cd TwFarmer
cargo build --release --locked
cd target/release
./twfarmer
```

Откроется меню управления. Если настройки и сессии уже есть, запускайте программу
из того же каталога, что и раньше. Старые файлы сессий читаются автоматически;
личные списки с прежними обозначениями переводятся на реальные логины Twitch.

Первый запуск можно настроить полностью через интерфейс: добавить аккаунт,
ввести общие каналы, выбрать аккаунты и запустить фарм.
При авторизации программа показывает ссылку Twitch. Откройте её на своём
компьютере или телефоне, войдите под нужным аккаунтом и скопируйте полученный
адрес с `#access_token=`. Вставьте адрес или сам токен в скрытое поле TwFarmer.
Пароль и 2FA вводятся только на Twitch. Программа определяет логин и проверяет
доступ к привязкам кампаний перед сохранением сессии.
TwFarmer не запускает браузер и не требует его установки, в том числе на VDS.

Полная ссылка входа выделена цветом в отдельном поле. `F2` копирует её в
интерфейсе и во время `login`. На локальном компьютере используются доступные
`wl-copy`, `xclip`/`xsel`, `pbcopy` или Windows `clip.exe`. Через SSH или без
системного буфера программа отправляет запрос буферу терминала. Если терминал
отказывает, адрес можно выделить вручную. `PgUp`/`PgDn` прокручивают поле адреса
в небольшом окне. TwFarmer сам не открывает браузер.

`./twfarmer login` использует тот же вход, что и интерфейс. Имя аккаунта не нужно:
существующая сессия найденного аккаунта заменяется с сохранением списков каналов.
`login --account ЛОГИН` дополнительно проверяет, что токен относится к ожидаемому
аккаунту. Для скриптов `login --stdin` читает токен или адрес из стандартного ввода.
Не помещайте токены в аргументы команд, историю shell или публичные журналы.

[Ссылка входа Twitch](https://www.twitch.tv/login?client_id=kd1unb4b3q4t58fwlpcbzcbnm76a8fp&redirect_params=client_id%3Dkd1unb4b3q4t58fwlpcbzcbnm76a8fp%26redirect_uri%3Dhttps%253A%252F%252Fwww.twitch.tv%252F%26response_type%3Dtoken)
использует нативный клиент, проверенный с API привязок кампаний. Обычный токен
сессии сайта может не дать такой доступ. Вход по коду устройства удалён.
Если старая сессия не читает привязки кампаний, программа попросит выполнить
`login` заново; отсутствие данных не означает, что игровой аккаунт не подключён.

При этом способе входа `refresh_token` не выдаётся. У проверенного нативного
токена `expires_in: 0`, но Twitch может его отозвать. Если токен станет
недействительным, войдите заново. Для сохранённых сессий с refresh-токеном
автоматическое обновление продолжает работать.

## Язык

По умолчанию программа работает на английском. В меню `m` / `F1` выберите
**Language / Язык**, затем **English** или **Русский** и нажмите `Enter`.
Выбранный язык сохраняется в поле `language` конфигурации и применяется сразу.
Отдельное переключение языка не перезапускает фарм.

Через команды:

```bash
./twfarmer language ru                 # сохранить русский
./twfarmer language en                 # сохранить английский
./twfarmer language                    # показать сохранённый язык
./twfarmer settings set --language ru  # тот же выбор через настройки
./twfarmer --lang ru --help            # русский только для текущей команды
./twfarmer --lang en run               # английский только для текущего запуска
```

`--lang` имеет приоритет над сохранённым языком и не изменяет файл конфигурации.
Явный выбор другого языка в интерфейсе сохраняет и применяет новый язык.
Имена команд, ключи конфигурации и логины Twitch одинаковы для обоих языков.
Интерфейс, справка, сообщения авторизации и новые записи журнала используют
выбранный язык; уже записанные события сохраняют исходный текст.
Старая конфигурация без поля `language` использует английский.

## Обновление программы

По умолчанию включено `auto_update = true`. Интерфейс, `run` и `daemon` проверяют
опубликованные стабильные релизы `Rednelss/TwFarmer` при запуске и каждые 24 часа.
Скачивание идёт параллельно с фармом. После проверки заменяется бинарник,
программа перезапускается с активными аккаунтами, временными каналами и состоянием
службы. В Linux сохраняется PID для systemd. Несохранённый ввод задерживает
перезапуск до сохранения или закрытия формы. Счётчики начинают новую сессию процесса.

```bash
./twfarmer update --check
./twfarmer update
./twfarmer settings set --auto-update false
```

В меню есть **Проверить обновления** и **Установить последнее обновление**.
Переключатель **Настройки фарма > Автообновление программы** управляет автоматической
установкой. `update --check` ничего не меняет. Отдельная команда `update` устанавливает
бинарник; после неё работающие экземпляры нужно перезапустить.

Программа выбирает архив своей ОС и архитектуры, сверяет его с `SHA256SUMS`
и читает только исполняемый файл. Настройки и токены сохраняются. Для установки
нужны права записи в каталог программы. Сборки GitHub поддерживают Linux x86_64
с glibc 2.35+, Windows x86_64 и macOS Apple Silicon. Для остальных платформ
используйте сборку из исходников. При ошибке фарм продолжается, повтор через шесть часов.
При переходе с версии без обновления один раз установите 0.3.0 вручную.

## Управление через интерфейс

`m` или `F1` открывает меню, `↑/↓` выбирает пункт, `Enter` выполняет,
`Esc` закрывает форму или отменяет вход. Все операции доступны в меню:

- Запуск и остановка фарма выбранных аккаунтов.
- Проверка балансов без просмотра и получения бонусов.
- Выбор аккаунтов для запуска: пробел переключает выбор, `a` выбирает все,
  `n` снимает выбор, `Enter` сохраняет, `t` применяет только на текущий запуск.
- Добавление аккаунта, обновление входа и удаление локальной сессии.
- Общие каналы, личные каналы аккаунта и возврат к общему списку.
- Временный список каналов для текущего запуска.
- Настройки фарма, открытие другого файла конфигурации или создание нового.
- Доступные кампании Drops и условия каждой награды.
- Переключение между таблицей и журналом, выбор языка, помощь и выход.

В формах каналов принимаются логины или ссылки Twitch через пробел/запятую.
Пустой личный список возвращает аккаунт к общему. Пустой временный список
возвращает сохранённые списки. В формах работают `←/→`, `Home/End`,
`Backspace/Delete`, вставка текста и `Ctrl+U` для очистки.
В настройках `Tab` или `↑/↓` переключают поля, `←/→` или пробел меняют
переключатели и варианты. `Enter` сохраняет, `Esc` отменяет изменения.
F2 показывает технические поля: интервалы опроса и просмотра.
При скрытии этих полей их значения сохраняются.

Общие и личные каналы, настройки и выбор аккаунтов сохраняются.
Временные каналы действуют на все выбранные аккаунты только в текущем процессе
и имеют приоритет над общими и личными списками.
Изменение настроек во время фарма перезапускает выбранные аккаунты с новыми
параметрами; накопленные показатели панели сохраняются.
Проверка балансов без фарма останавливает просмотр. Добавление аккаунта
показывает код, пока остальные аккаунты продолжают работать.

На главном экране:

- `s`: запустить, `x`: остановить, `a`: добавить аккаунт, `c`: общие каналы.
- `d`: кампании Drops, `p`: настройки фарма, `?`: помощь.
- `↑/↓` или `j/k`: выбранный канал, `Tab`: фильтр аккаунтов.
- `PgUp/PgDn`: прокрутка, `l`: журнал.
- `q` или `Ctrl+C`: выйти.

Каналы сортируются по состоянию: фарм, запуск, повтор, онлайн, очередь, проверка, остановленные, ошибки, отключённые баллы, офлайн. Внутри одного состояния сохраняется исходный порядок. Выбранная строка остаётся на том же канале при перемещении. Приоритет просмотра берётся из настроек.

Панель обновляется каждые 250 мс. Видны баланс, изменение за текущую сессию
программы, бонусы, состояние канала и ошибки. На широком экране дополнительно
показаны активное время и время с последнего обновления баланса или Drops.
Выбранная строка показывает подробности и время последнего успешного просмотра.
Успешное обращение к потоку само по себе не подтверждает начисление баллов.
Обычный журнал сообщает об изменениях баланса и наград, не повторяя неизменившиеся
значения при каждом опросе. Панель продолжает показывать актуальное состояние.

Каждый аккаунт работает независимо и смотрит до двух каналов одновременно.
Ошибка одного аккаунта не останавливает другие. Порядок каналов задаёт приоритет;
при завершении эфира выбирается следующий подходящий онлайн-канал.

## Присутствие в чате

Во время фарма каждый аккаунт подключается к чату всех каналов из своего общего,
личного или временного списка, включая офлайн-каналы. Соединение использует TLS
на `irc.chat.twitch.tv:6697`, отвечает на служебные PING и восстанавливается
после обрывов. При обновлении сессии чат получает новые данные входа.
Работа чата не задерживает запросы просмотра.

По умолчанию `chat_presence` включён. Переключить его можно через
**Настройки фарма > Присутствие в чате** или командой:

```bash
./twfarmer settings set --chat-presence true
./twfarmer settings set --chat-presence false
```

В подробностях канала отображаются состояние чата и ошибки. В терминалах
шириной от 130 символов появляется столбец `ЧАТ`. Остановка фарма, проверка
балансов и выход закрывают соединение с чатом. Программа не отправляет сообщения
в чат и не сохраняет входящие сообщения в файлы или журнал.

StreamElements и другие боты ведут свои балансы лояльности. Начисление за
присутствие в чате зависит от настроек бота у стримера; отдельные правила могут
требовать активности или онлайн-трансляции. Баланс в панели относится к баллам
канала Twitch. Список пользователей чата на сайте Twitch может обновляться с задержкой.
Если Twitch отклоняет вход в IRC, обновите вход в аккаунт.

## Команды

Команды сохранены для скриптов. Везде используются реальные логины Twitch.

```bash
./twfarmer                                      # меню управления
./twfarmer ui                                   # то же
./twfarmer login                                # добавить / обновить аккаунт
./twfarmer login --account twitch_user               # обновить вход именно twitch_user
./twfarmer accounts add                         # добавить без отдельного имени
./twfarmer accounts add welovegames lizabaktt    # добавить и задать личные каналы
./twfarmer accounts list
./twfarmer channels welovegames betboom_cs_ru
./twfarmer accounts channels twitch_user lizabaktt
./twfarmer accounts channels twitch_user             # вернуть общий список
./twfarmer run                                  # фарм и интерфейс
./twfarmer run --account twitch_user,another_login
./twfarmer run --account twitch_user welovegames      # временные каналы
./twfarmer run --no-ui                           # обычный журнал
./twfarmer status --account twitch_user
./twfarmer accounts remove twitch_user
./twfarmer logout --account twitch_user
./twfarmer --config /полный/путь/settings.toml
```

`run` использует сохранённый выбор аккаунтов. Если выбор ещё не сохранён,
запускаются все аккаунты. Явный `--account` меняет выбор только для запуска.
`run CHANNELS` меняет списки только на текущий запуск.
При перенаправлении вывода программа использует обычный журнал.
`init CHANNELS` создаёт настройки и не перезаписывает существующий файл.
`logout` без логина допустим, если сохранён только один аккаунт.

Удаление локальной сессии не отзывает доступ на Twitch; для этого есть
https://www.twitch.tv/settings/connections.

| Остановить фарм | `stop` |
| Проверить балансы | `status --account LOGIN` |
| Сохранить выбор аккаунтов, Enter | `accounts select LOGIN1 LOGIN2` |
| Снять выбор всех аккаунтов | `accounts select` |

| Удалить аккаунт и его настройки | `accounts remove LOGIN` или `logout --account LOGIN` |

| Очистить общие каналы | `channels --clear` |
| Личные каналы | `accounts channels LOGIN CHANNELS` |
| Вернуть общий список | `accounts channels LOGIN` |
| Временные каналы | `run CHANNELS` или `start CHANNELS` |
| Убрать временные каналы | `start` без каналов |
| Настройки | `settings show`, `settings set OPTIONS` |

| Доступные кампании Drops | `drops --account ЛОГИН` |
| Автопоиск каналов Drops | `settings set --auto-drops true` или `false` |
| Приоритет баллов или Drops | `settings set --farming-priority points` или `drops` |
| Открыть конфигурацию | `--config PATH ui` |
| Создать конфигурацию, в том числе пустую | `--config PATH init [CHANNELS]` |
| Журнал вместо таблицы | `ui --journal`, `run --journal`, `journal` |
| Вернуться к таблице | `journal --enabled false` |
| Переключиться на обычный журнал без интерфейса | `run --no-ui` |
| Перечитать настройки | `reload` |
| Язык | `language en`, `language ru`, `settings set --language en` |
| Помощь / версия | `--help`, `--version` |
| Закрыть программу | `quit`, Ctrl+C |

`start`, `stop`, `reload`, `journal` и `quit` обращаются к запущенной программе
для того же пути конфигурации. Пример из второго терминала:

```bash
./twfarmer settings set --max-channels 1 --claim-bonus false
./twfarmer accounts select twitch_user
./twfarmer start --account twitch_user welovegames
./twfarmer stop
./twfarmer reload
./twfarmer quit
```

Изменения каналов, настроек и сохранённого выбора через команды автоматически
применяются в открытой программе. Временный выбор и списки не записываются на диск.
`settings set` поддерживает `--max-channels`, `--poll-interval-seconds`,
`--watch-interval-seconds`, `--claim-bonus true|false`,
`--chat-presence true|false`, `--farm-drops true|false`, `--claim-drops true|false`,
`--language en|ru`.
Также поддерживается `--auto-drops true|false` для автопоиска кампаний и каналов.
Приоритет задаётся через `--farming-priority points|drops`.

Меню «Обычный журнал» освобождает экран и выключает управление клавишами;
фарм продолжает работать. В интерактивном терминале `journal` снова открывает
интерфейс. Одновременно запускается один экземпляр для каждого пути конфигурации.
Файлы `*.control.json` и `*.control.lock` служат локальному управлению и исключены
из Git; адрес управления содержит отдельный случайный ключ, а не токен Twitch.

## Запуск через systemd

Для запуска только уже настроенных аккаунтов:

```bash
./twfarmer --config /полный/путь/twfarmer.toml daemon
```

`daemon` всегда работает без интерфейса и чтения stdin, даже в обычном терминале.
Он требует существующую конфигурацию и сохранённые сессии: при отсутствии настроек,
аккаунтов или каналов завершится с ошибкой, которую видно в журнале. Пустой список
каналов допустим при включённом автопоиске Drops. Новая авторизация
не запускается. Действующие сессии проверяются и обновляются как при обычном фарме;
если нужен повторный вход, выполните `login` отдельно.
Используется `enabled_accounts` из конфигурации. Если поле не задано, запускаются
все сохранённые аккаунты. Можно ограничить запуск: `daemon --account LOGIN1,LOGIN2`.
Каналы берутся из общих и личных списков конфигурации. `SIGTERM` и `Ctrl+C`
завершают работу с кодом 0 и освобождают блокировку экземпляра.

Пользовательский unit `packaging/twfarmer.service` использует
бинарник `~/.local/bin/twfarmer` и конфигурацию
`~/.config/twfarmer/twfarmer.toml`. Установка из распакованного Linux-архива:

```bash
install -Dm755 twfarmer ~/.local/bin/twfarmer
mkdir -p ~/.config/twfarmer ~/.config/systemd/user
cp packaging/twfarmer.service ~/.config/systemd/user/twfarmer.service
~/.local/bin/twfarmer --config "$HOME/.config/twfarmer/twfarmer.toml" ui
```

В интерфейсе сохраните аккаунты и каналы, затем закройте программу.
Если настройка уже выполнена в другом каталоге, предварительно перенесите
`twfarmer.toml`, каталог `twfarmer.toml.accounts` и старый
`twfarmer.toml.auth.json`, если он есть, в `~/.config/twfarmer`.
Сохраняйте имена файлов и права доступа. Для сборки из исходников в команде
`install` используйте `target/release/twfarmer` вместо `twfarmer`.

Включите службу:

```bash
systemctl --user daemon-reload
systemctl --user enable --now twfarmer.service
```

Управление службой:

```bash
systemctl --user status twfarmer.service
journalctl --user -u twfarmer.service -f
systemctl --user reload twfarmer.service
systemctl --user stop twfarmer.service
```

Для запуска при загрузке системы до входа пользователя и работы после выхода:

```bash
loginctl enable-linger "$USER"
```

Служба остаётся процессом на переднем плане под управлением systemd.
При ошибке systemd повторяет запуск через 30 секунд. Программа и команды управления
используют один и тот же полный путь `--config`.

## Настройки и сессии

Настройки привязаны к текущему каталогу либо к пути `--config`.
Пример конфигурации: `twfarmer.example.toml`.

- `language`: `en` или `ru`; по умолчанию `en`.
- `channels`: общие каналы.
- `[account_channels]`: личные списки, например `twitch_user = ["welovegames"]`.
- `enabled_accounts`: сохранённый выбор логинов; пустой список означает, что никто
  не выбран. Отсутствующее поле означает все аккаунты.
- `max_channels`: всего видеослотов на аккаунт, 1 или 2, включая Drops.
- `farming_priority`: `points` (по умолчанию) или `drops`.
- `poll_interval_seconds`: опрос балансов, 30-3600 с; по умолчанию 60.
- `watch_interval_seconds`: обращение к потоку, 15-60 с; по умолчанию 20.
- `claim_bonus`: автоматическое получение бонусов.
- `chat_presence`: присутствие в чатах настроенных каналов; по умолчанию `true`.
- `farm_drops`, `claim_drops`: Drops за просмотр и автосбор; по умолчанию `true`.
- `auto_drops`: автоматически искать доступные кампании и каналы; по умолчанию `false`.
- `auto_update`: автоматически устанавливать стабильные релизы GitHub; по умолчанию `true`.
Прежние настройки `client_id` и `oauth_scopes` игнорируются. Каждая сессия
использует свой ID клиента, проверенный Twitch.

Новые сессии сохраняются в `twfarmer.toml.accounts/TWITCH_LOGIN.auth.json`.
Прежний `twfarmer.toml.auth.json` и другие старые файлы продолжают использоваться.
На Unix новые файлы получают права 0600, каталог аккаунтов создаётся с правами 0700.
Файлы содержат токены и исключены из Git. Токены не выводятся в журнал и
не передаются CDN. При повторной авторизации выбранного аккаунта вход в другой
Twitch-аккаунт отклоняется; прежняя сессия сохраняется.

Сессия проверяется при запуске и каждые 5 минут. Токен с `expires_in = 0`
действителен при успешной проверке Twitch. При сетевых ошибках просмотр повторяется
с увеличением задержки до 5 минут. Авторизация отменяется через `Esc`.

Программа загружает сегмент потока низкого качества и отправляет `minute-watched`
каждые 20 секунд по умолчанию. Видео не воспроизводится и не записывается на диск.
Адрес событий берётся из настроек Twitch; при `use_beacon_url = true` используется
`beacon_url`. ID зрителя передаётся числом.

Решение о начислении принимает Twitch. На новом канале первые баллы обычно
приходят через несколько минут. Официальный API не предоставляет фарм баллов;
используемые внутренние запросы могут измениться. Автоматический фарм может
противоречить правилам Twitch. Ставки и расходование баллов не предусмотрены.

## Drops

Drops за просмотр включены по умолчанию. Добавьте участвующие каналы в общий
или личный список и запустите фарм:

```bash
./twfarmer run whoplohoyparen --account ВАШ_ЛОГИН
./twfarmer settings set --farm-drops true --claim-drops true
```

Те же переключатели находятся в **Настройки фарма > Фармить Drops / Забирать Drops**.
Пункт **Доступные кампании Drops** показывает награды выбранных аккаунтов,
прогресс и условия, которые мешают фарму. Сначала видны доступные и готовые
к получению награды. Tab показывает все кампании, включая заблокированные
и завершённые. `↑/↓` или `PgUp/PgDn` выбирают награду, её подробности видны
под списком. Enter раскрывает подробности с прокруткой и возвращает к списку.
`r` обновляет, `Esc` закрывает окно; фарм продолжает работать.
Команда `./twfarmer drops --account ВАШ_ЛОГИН` читает те же данные.
В широкой таблице есть колонка DROPS. Подробности канала и журнал показывают
кампанию, награду и минуты от Twitch. Команда `status` тоже читает Drops,
не запуская просмотр и не забирая награды. Неизвестный прогресс отображается
как `?`. Локальный таймер не используется. При включённом фарме Drops опрос
происходит не реже раза в минуту.

Drops используют не более одного видеопотока на аккаунт. `max_channels` ограничивает
все потоки баллов и Drops вместе. Отключённые баллы канала не мешают Drops.
Присутствие в чате сохраняется на всех настроенных каналах.

По умолчанию `farming_priority = "points"`: доступные онлайн-каналы общего или
личного списка занимают слоты по порядку. Если осталось место, добавляется канал
Drops. При `farming_priority = "drops"` сначала выбирается один поток Drops,
а второй слот занимает настроенный канал для баллов. Если один поток даёт и баллы,
и Drops, он занимает один слот и оставляет место для другого канала баллов.
При `max_channels = 1` выбирается доступный тип фарма с более высоким приоритетом.

```bash
./twfarmer settings set --farming-priority points
./twfarmer settings set --farming-priority drops
```

Тот же выбор есть в **Настройки фарма > Приоритет фарма**. Журнал и
подробности канала показывают роль каждого выбранного потока. В смешанном режиме
запросы канала баллов отправляются перед запросом просмотра Drops; минуты и баланс
по-прежнему приходят от Twitch. Два отдельных потока Drops не дали устойчивого
прогресса в обеих кампаниях и не выбираются вместе.

Когда на выбранном канале больше нет доступных Drops, выбирается другая кампания.
Показанные минуты приходят от Twitch, а не от локального таймера.

Автосбор требует статуса `CLAIMABLE` от Twitch. Полный счётчик минут сам по себе
не подтверждает готовность награды. Для повторяемых кампаний показываются
количество полученных наград и время следующего просмотра, если Twitch его
вернул. Для каждого аккаунта и награды полученное окно просмотра ставится
на паузу до `nextEligibleAt` или `currentWindow.expiresAt`. Если время сброса
неизвестно, программа ждёт нового прогресса или доступности от Twitch
и не назначает дату по локальному календарю. Освободившийся слот может занять
другая доступная кампания. Например, GTAVI Launch Celebration требует час просмотра в разные
дни для ежедневных наград.

Награды за подписки и с дополнительными условиями не выбираются для просмотра.
Привязку аккаунтов и ручной выбор наград нужно выполнить на Twitch. Если награда
является сундуком, его содержимое и открытие определяет Twitch. Программа ничего
не покупает. Учёт просмотра зависит от Twitch, а внутренний API Drops может измениться.

Для поиска каналов без ввода их имён включите автоматический режим:

```bash
./twfarmer settings set --auto-drops true --farm-drops true
./twfarmer run --account ВАШ_ЛОГИН
```

В интерфейсе это **Настройки фарма > Автопоиск каналов Drops**. Режим работает
с пустым списком каналов, в том числе через `daemon`/systemd. Настроенные каналы
занимают слоты согласно выбранному приоритету фарма. Если есть место для Drops,
программа ищет один онлайн-канал из разрешённого списка кампании или её категории.
В категории проверяются до
100 трансляций с включёнными Drops. Перед просмотром доступность награды
проверяется на самом канале. Найденные каналы появляются в таблице и хранятся
в памяти, не меняя сохранённые списки. Присутствие в чате распространяется
и на выбранный автоматический канал.

Каждый аккаунт перечитывает каталог кампаний раз в пять минут, пока для
автоматических Drops есть место. Если при приоритете баллов все слоты заняты
настроенными каналами баллов, автопоиск откладывается до появления свободного слота.
Команда `drops` и окно кампаний загружают полный каталог по запросу.
Полученные награды,
дневная пауза или завершение эфира позволяют перейти к другой доступной кампании.
Если подходящего эфира нет, поиск повторяется при следующем опросе. Привязка
игрового аккаунта и выполнение предварительных условий проверяются под каждым
аккаунтом отдельно. Неизвестные или невыполненные условия отображаются в списке.
При включённом `claim_drops` готовые награды забираются и из каталога кампаний.
Уже выполненные платные условия могут открыть награду за просмотр, но программа
сама не покупает подписки и не связывает аккаунты. Чтобы использовать только
настроенные каналы, отключите `auto_drops`.

Если Twitch уже засчитал минуты, просмотр может продолжаться даже при противоречивом
поле привязки аккаунта. Попытка получения требует статуса `CLAIMABLE`, а результат
должен подтвердить Twitch. Сам флаг привязки не подтверждает выдачу награды.

## Проверка

```bash
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
```

Тесты проверяют перенос имён и настроек, изоляцию аккаунтов, формы и действия
интерфейса, сохранение показателей при перезапуске, OAuth, HLS и ошибки Twitch.
Реальное начисление нескольким аккаунтам требует входа в каждый аккаунт
и работающих эфиров.
